# 👋 Start Here

Welcome to the course! Follow the sequence; don't rush straight to advanced commands.

## Before you begin

- [ ] A Windows, macOS or Linux computer
- [ ] Internet access for GitHub and learning resources
- [ ] Git installed (see `02-SETUP/`)
- [ ] A text editor such as VS Code (optional but useful)
- [ ] A free GitHub account if you want to publish and collaborate
- [ ] A separate folder for experiments

## Course navigation

1. Read `01-FOUNDATIONS/01-git-and-version-control.md`.
2. Install and configure Git using `02-SETUP/`.
3. Work through every command in `03-CORE-COMMANDS/`.
4. Practise safe recovery in `04-TRACKING-AND-UNDO/`.
5. Learn branches and conflicts in `05-BRANCHING-AND-MERGING/`.
6. Connect to GitHub in `06-GITHUB-REMOTE/`.
7. Practise team workflows in `07-COLLABORATION/`.
8. Continue with advanced topics and projects.
9. Test yourself with `11-REVISION/`.

## How to study each lesson

1. Read the concepts.
2. Type the command yourself rather than copy-pasting everything.
3. Predict what the command will do before pressing Enter.
4. Check the result with `git status`, `git log` or `git diff`.
5. Write a short note in your own words.
6. Complete the lesson's exercise.

## Golden rule

Use a practice repository for experiments. Never practise risky reset, restore, rebase, or history-rewriting commands on important work.
