# 🗺️ Course Roadmap and Outcomes

## Level 1 — Beginner

**Modules:** Foundations, setup, core commands.

You should be able to explain version control, configure Git, create a repository, stage changes, commit, and read history.

## Level 2 — Independent user

**Modules:** Tracking/undo, branches, GitHub remote.

You should be able to ignore generated files, make a feature branch, merge it, connect to a remote, and push/pull changes.

## Level 3 — Collaborator

**Modules:** Pull requests, issues, reviews, conflicts, security.

You should be able to contribute through a branch and pull request, respond to review feedback, and resolve a conflict carefully.

## Level 4 — Intermediate

**Modules:** Stash, rebase, tags, reflog, project capstone.

You should understand when advanced commands are appropriate and know how to recover from common mistakes.

## Weekly checkpoint

- Week 1: Can create and inspect commits without a tutorial.
- Week 2: Can use branches and recover safely from simple mistakes.
- Week 3: Can publish a repo and use a pull request.
- Week 4: Can complete the capstone and explain the workflow.
