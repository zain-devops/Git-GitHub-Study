# 🌐 Optional — Publish Your Course with GitHub Pages

GitHub Pages can publish static websites from a repository. This course is currently written in Markdown; GitHub displays Markdown files directly in the repository, and Pages can publish a site when configured with a supported static-site workflow.

## Before you start

- Push the course repository to GitHub.
- Read the current official GitHub Pages documentation.
- Check the repository's visibility and any plan limitations that apply to your account.

## Official guide

Follow the current instructions at: https://docs.github.com/en/pages

The setup screens and available publishing options can change, so use the official guide rather than relying on old screenshots.

## Suggested next improvement

Convert the course into a Jekyll-based documentation site or another static-site generator, then configure Pages to build and publish it. Keep the Markdown source files in version control so edits can be reviewed.
